Read the result within its limits.

Random vocabulary baseline: 6.25% expected accuracy. Uniform over the four context values: 25%. Always choosing the first value: 25%. Dictionary oracle: 100%. Head numbers do not identify the same learned function across seeds. The report uses no external assets or network requests.

Protocol and interpretation

Architecture: two pre-LN causal transformer layers, four heads per layer, width 64, MLP width 128. Training: 16,384 unique dictionaries, development: 512, evaluation: 512; split by a hash of the canonical dictionary. Three seeds: 11, 29, 47. Checkpoints selected only on development accuracy and loss. The no-op clones head outputs without changing values. Uncertainty uses 2,000 paired bootstrap resamples (seed 20261011). Attention ranks and probability-drop ranks use average ranks for ties; constant rankings have undefined correlation. Matrices are limited to 16 preregistered examples per model.

Attention describes routing weights. Zero ablation measures one particular intervention and can produce unusual internal states. Neither is a complete causal explanation. Residual paths, value content, compensation and head interactions remain untested. This fixed, simple synthetic task does not establish behavior in natural language or larger models.
